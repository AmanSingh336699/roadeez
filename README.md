# ROADEEZ - Riding Gear & Accessories E-Commerce Store

**ROADEEZ** is a modern, responsive React-based e-commerce platform designed for motorcycle enthusiasts, offering premium helmets, riding jackets, gloves, boots, and accessories.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React 19
- **Build Tool:** Vite
- **Routing:** React Router DOM (v7)
- **Styling:** Vanilla CSS (Custom Design System with Dark Theme & Glassmorphism)

---

## ✨ Features

- **Product Catalog:** Browse by Category (Helmets, Jackets, Gloves, Boots, Accessories) and Brands.
- **Search & Filters:** Filter products by brand, price range, and custom search query.
- **Product Details:** Detailed specifications, size/color selectors, and image galleries.
- **Interactive UI:** Smooth transitions, responsive navigation, micro-animations, and dynamic cart state.
- **Pages:** Home, Products Catalog, Product Details, About Us, and Contact.

---

## 🚀 Quick Start (Setup & Run Instructions)

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

### 2. Installation
Navigate to the project root directory and install dependencies:

```bash
cd roadeez
npm install
```

### 3. Run Development Server
Start the Vite local development server:

```bash
npm run dev
```

Open your browser and navigate to:
```
http://localhost:5173
```

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev` — Starts the development server with HMR.
- `npm run build` — Builds the app for production to the `dist` folder.
- `npm run preview` — Locally previews the production build.
- `npm run lint` — Runs ESLint to check for code formatting and standard issues.
